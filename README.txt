AMRITA & SACHIN — DEVOTIONAL PREMIUM WEDDING WEBSITE

Included:
- index.html: website with welcome intro, rope interaction, scratch-to-reveal golden invitation card, and main page
- soundtrack.mp3: existing soundtrack
- assets/: intro artwork and Shiva–Parvati artwork

Install:
1. Back up your GitHub Pages repository.
2. Replace index.html and soundtrack.mp3 in the repository root with the included files.
3. Upload/merge the included assets/ folder into the repository root.
4. Keep your existing wedding photos, videos, and other media files in their original paths; this update does not replace them.
5. Commit and push to GitHub Pages.

Main homepage devotional details:
- The hero now displays “ॐ श्री गणेशाय नमः ॐ” above a small gold vector illustration of Lord Shiva and Maa Parvati.
- The caption “शिव-पार्वती का आशीर्वाद” appears beneath the illustration.
- Amrita's name is placed before Sachin throughout the couple branding.

Intro flow:
1. Welcome blessing — tap “Tap to begin”.
2. Pull the invitation rope.
3. Scratch the golden card to reveal the invitation details.
4. The intro closes and the main website opens.

Audio:
The soundtrack remains silent throughout the welcome, rope, and scratch-card stages. It starts only when the main page opens. Browser autoplay policies may still require a user interaction on some browsers.

The welcome intro appears once per browser session. “Replay welcome blessing” in the footer clears the session flag and reloads the intro. No Skip or separate Open Invitation button is included.
